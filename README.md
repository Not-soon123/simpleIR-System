# Information Retrieval System - Inverted Index & Vector Space Model

## 📋 Project Overview

This project implements a complete Information Retrieval (IR) system that supports:
- **Inverted Index Construction** with TF, DF, CF, and position information
- **Vector Space Model** for document ranking
- **Interactive Query Processing** with cosine similarity
- **Dynamic Document Loading** from text files

## 🎯 Assignment Requirements Met

| Requirement | Implementation |
|-------------|----------------|
| Select a language | English (can be adapted to any language) |
| Construct inverted index | ✅ Complete index with TF, DF, CF, positions |
| Generate index terms | ✅ With preprocessing (tokenization, stopwords, stemming) |
| Position/location info | ✅ Stored per term per document |
| Vector Space Model | ✅ TF-IDF weighting + cosine similarity |
| Two or more queries | ✅ Interactive system supports unlimited queries |
| Ranked retrieval | ✅ Documents sorted by similarity score |

## 🚀 Features

- **Dynamic document loading** - Load any number of text files from a folder
- **Interactive query system** - Enter queries at runtime (no hardcoding)
- **Real-time preprocessing** - Stopword removal, stemming, tokenization
- **Complete inverted index** - Shows TF, DF, CF, and term positions
- **Cosine similarity ranking** - Documents ranked by relevance
- **Multi-query support** - Process unlimited queries in one session
